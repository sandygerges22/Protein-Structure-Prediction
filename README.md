Project Title: Predicting Protein Structural Domains using Machine Learning
Project Overview
This project provides an automated bioinformatics pipeline to classify proteins as either "Cellular Component" or "Soluble" based on their physicochemical properties. By leveraging machine learning, this tool helps researchers overcome the time-consuming and costly nature of experimental structural protein analysis.

Key Features
Data Pipeline: A robust cleaning process for over 80,000 protein entries, ensuring data integrity.

Feature Engineering: Includes a custom hydrophobic_ratio feature to better identify membrane-spanning characteristics.

Model Performance: The final model achieved 99% accuracy, with 99% Precision and 100% Recall.

Deployment: A live web application built with Streamlit, allowing users to perform real-time structural category predictionsHow to run the application
Clone this repository.

Install the necessary requirements: pip install -r requirements.txt.

Run the Streamlit app: streamlit run app.py
